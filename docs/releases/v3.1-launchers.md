# Hunter's Atlas 3.1

Two player downloads, one Atlas version:

- **Windows:** Bloodborne for Windows v1.9 (Supermedo).
- **Lantern:** Atlas edition based on Awakenchan's Lantern Engine v0.9.37.

Both include all 16 illustrated maps. The map background now continues through
the center, and the heavy green edge has been replaced by a thinner warm-toned
outline. Cathedral Ward and Forbidden Woods screenshots show the updated look.

Extract the whole ZIP into a new folder, run **Install.cmd**, select your
**CUSA00207 Bloodborne 1.09** folder and your existing save folder containing
`savedata`, then **Play → Continue**. Keep a save backup.

Enable Atlas under **Mods & patches** in the Windows edition, or under
**Settings → Hunter's Atlas 3.1 → Enable Hunter's Atlas** in the Lantern edition.
A separate Atlas entry in Lantern's ordinary Mods list is not required.

Open the in-game menu and choose **Map**, or press **M**. Select an eligible
discovered lamp to travel. [Installation guide](https://github.com/MikeTat1988/HuntersAtlas/blob/v3.1-launchers/docs/INSTALL-LAUNCHERS.md).

The two editions use independent launcher profiles. Existing Atlas installations
and the previous Windows release remain available. Game files, saves, personal
profiles and generated shader caches are not shipped. Checksums and corresponding
source accompany the release.
