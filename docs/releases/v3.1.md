# Hunter's Atlas 3.1

[Windows download](https://github.com/MikeTat1988/HuntersAtlas/releases/download/v3.1/Hunters-Atlas-3.1-Windows.zip)

All 16 supported areas now use continuous supported navigation paths, illustrated
surroundings and a separate aligned legend. Ordinary slopes stay whole; local
overlapping passages follow the player's actual height, with Upper/Lower overrides.
Selecting a passage covers only its real footprint and preserves nearby routes.

All geometry, outlines, art meshes and fog groups are prepared offline. The game
decodes and draws the included hashed data; no collision extraction or triangulation
runs while playing. The Windows runtime, Python, DLLs, launcher cache-recovery fix
and integrity checks are included.

Extract into a new folder, run Install.cmd and select your own CUSA00207 1.09 game
and existing save folder. Open HuntersAtlas.exe, Play/Continue, and press M.

The unchanged compiled runtime passed 28 offscreen resolution/zoom cases across
seven output sizes, including live resizing. All 16 maps passed native render
and private visual review. The clean ZIP has fresh-extraction hash/contract checks.
See [QA](../QA.md) for exact scope and remaining source/gameplay qualifications.

Game files, saves, personal profiles and generated shader caches are not shipped.
The Source ZIP includes the corresponding native baseline and dependency sources.
Atlas 3.1 is supported; earlier versions are legacy.
